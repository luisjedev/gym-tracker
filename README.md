# Gym Tracker

Aplicación móvil Android personal para registrar objetivos diarios y semanales relacionados con el cambio físico.

## Stack previsto

- React Native
- Expo
- TypeScript
- Persistencia local en el dispositivo

El proyecto comenzará validando una development build de Expo en un teléfono Android físico, sin emuladores.

La especificación del MVP se encuentra en [`.scratch/gym-tracker-mvp/spec.md`](.scratch/gym-tracker-mvp/spec.md).
